# Polyimide-Mechanics
Selected supporting information for the study of the mechanical properties of aromatic polyimides.
# PI_Mechanics_Predictor.exe
An executable programs (.exe) for single-molecule and batch property predictions and for interpretability analysis of the prediction results based on molecular similarity maps.
# monomers_smiles.csv
The SMILES representations of all dianhydride and diamine monomers involved in this study.
# Gaussian_vs_MSE.csv
Polyimide structures used for comparing machine learning models based on Gaussian NLL loss and MSE loss.
# ML_vs_Physical.csv
Polyimide structures used for comparing Gaussian NLL loss ML models and physics-based models.
# Distribution of mechanical properties of polyimide.html
Interactive HTML point-cloud visualizations of the modulus, fracture stress, toughness, and temperature-dependent decay rate of fracture stress across the polyimide chemical space.
